### GENG
This is a simple code-only game engine using the Monogame framework.<br>


## Features* 

Collision, premade effects (such as particles, drops, explosions...)<br>
basic light/dark lighting system using light sources, tilemaps and <br>
probably some other things Ill think of later .

## Run
Requires .NET and Monogame <br>

*most features not yet implemented.
